| Concept                                | Important method                    |
| -------------------------------------- | ----------------------------------- |
| **Thread creation**                    | `extends Thread`                    |
| **Runnable creation**                  | `implements Runnable`               |
| **Start Thread**                       | `start()`                           |
| **Thread work**                        | `run()`                             |
| **Callable work**                      | `call()`                            |
| **Pause Thread**                       | `sleep()`                           |
| **Wait for Thread**                    | `join()`                            |
| **Check Thread State**                 | `getState()`                        |
| **Thread communication**               | `wait()`, `notify()`, `notifyAll()` |
| **Executor task submission**           | `submit()`                          |
| **Executor task execution**            | `execute()`                         |
| **Executor graceful shutdown**         | `shutdown()`                        |
| **Executor forceful shutdown attempt** | `shutdownNow()`                     |
| **Wait for Executor**                  | `awaitTermination()`                |
| **Future result**                      | `get()`                             |
| **Future status**                      | `isDone()`                          |
| **Future cancellation**                | `cancel()`                          |
| **Mutual exclusion**                   | `synchronized`                      |
